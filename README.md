# RuleInk

A lightweight, framework-agnostic PHP rules engine that turns field metadata into reusable expressions you can evaluate against one subject or apply to a datasource.

## Requirements

- PHP 8.2+

## Installation

```bash
composer require teonator/ruleink
```

## Testing

```bash
composer install
vendor/bin/phpunit
```
